# Backend Changes Log

## 1. `GoogleRoutesClient.java` (src/main/java/com/OdysseyAi/demo/travel/client/GoogleRoutesClient.java)
- **What was changed**: Modified `parseResponse` method.
- **Why**: When Google Routes API returned no route (e.g. asking for a Transit route where no transit exists), it would throw an `IllegalStateException("Google Routes returned no route.")`. This crashed the entire recommendation API flow. 
- **Fix**: Replaced the exception with a fallback mechanism that returns an empty `RouteData` object (duration=0, distance=0, polyline="") so the AI builder can gracefully ignore missing transit options instead of crashing.

## 2. `SecurityFiltersConfig.java` (src/main/java/com/OdysseyAi/demo/auth/configuration/SecurityFiltersConfig.java)
- **What was changed**: Modified `requestMatchers` in `securityFilterChain`.
- **Why**: Swagger API was failing to load the remote configuration because the `/v3/api-docs/**` endpoints were blocked by Spring Security.
- **Fix**: Added `"/v3/api-docs/**", "/swagger-resources/**", "/webjars/**"` to the `permitAll()` list.
